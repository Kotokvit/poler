# Модель угроз: архивы как вектор атаки

Архив — классический носитель атак: zip-slip (path traversal), бомбы
(decompression bomb), подмена содержимого после передачи. POLER закрывает
все три класса; POLER BOX добавляет четвёртый уровень — исполнение
недоверенного payload.

## Уровень 1. Формат

- **Целостность по construction**: SHA-256 всего потока (трейлер) +
  SHA-256 каждой записи (таблица). Любая порча ловится `verify` /
  `extract_all` (`files_bad`), неповреждённые записи извлекаются.
- **Crash-safety**: `.poler.part` → атомарный rename; «недописанный»
  архив не существует под финальным именем. Sidecar-файл содержит
  только метаданные — утечки содержимого через temporaries нет.

## Уровень 2. Распаковка (`poler extract`)

- **zip-slip**: `safe_rel_path` отклоняет абсолютные пути и `..`
  (`files_skipped_unsafe`); записи с небезопасными именами пропускаются
  с отчётом, остальные извлекаются.
- SHA-256 сверяется на месте, сразу после записи файла.

## Уровень 3. safe-extract (`poler-box safe-extract`)

Предфильтр бомб ДО распаковки:

- `--max-files` (def. 100 000) — число записей;
- `--max-total-mb` (def. 8192) — суммарный несжатый объём.

Архив 42.zip-типа (4 КБ → 4 ПБ) отклоняется до единого `write(2)`.

## Уровень 4. BOX (`poler-box run`)

Недоверенный исполняемый код внутри .poler-записи:

| Граница | Механизм |
|---|---|
| ФС хоста | pivot_root на tmpfs — корень хоста невидим |
| Процессы | pidns: payload = pid 1, хостовых pid не существует |
| Сеть | netns: только loopback, AF_INET/6 → EPERM (двойно) |
| Сисколы | seccomp-белой список (~140) + KILL смертельных |
| UID | userns через доверенный /usr/bin/unshare -Ur (rootless) |
| RAM/CPU | губернатор дерева + rlimits (rss_mb / cpu_s) |
| Исполнение | execveat(memfd) — без дубля бинарника на диск |

Rootfs коробки стримится из архива (RAM), образа ОС нет. Цикличность:
poler-engine сам может быть записью архива — коробка в коробке.

## Конфигурация по умолчанию

- `poler extract` — для СВОИХ архивов (доверенный источник, полный
  контроль SHA-256);
- `poler-box safe-extract` — для ЧУЖИХ архивов (лимиты + zip-slip);
- `poler-box run` — для недоверенного КОДА (полная изоляция).

## Открытые вопросы (roadmap)

- Точечная порча геометрии (индекс/трейлер) сейчас отклоняет архив
  целиком; v2 — dual-магия в заголовке каждого чанка для сканирования
  хвост-вперёд.
- `--archive-password`-шифрование записей (как у zip/AES) — не входит
  в v1; трейлер резервирует место под флаг encrypted.
